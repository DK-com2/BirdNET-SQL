# BirdNet データベースビューワー 音声詳細機能

## Phase 1: 基本的な詳細表示機能を追加しました

### 🎯 新機能
- データテーブルで行を選択可能
- 選択した行の詳細ページに移動
- 音声ファイルの基本情報表示
- 音声ファイルの再生機能

### 🚀 使用方法

1. **メインビューワーの起動**
   ```bash
   cd S:\python\BirdNet-win\streamlit_viewer
   streamlit run db_viewer.py
   ```

2. **データの検索・選択**
   - サイドバーで検索条件を設定
   - 検索結果のテーブルで任意の行をクリック
   - 「🎧 音声詳細を表示」ボタンが表示される

3. **音声詳細ページ**
   - 検出情報（種名、信頼度）
   - 時間情報（開始・終了時間）
   - ファイル情報（ファイル名、セッション）
   - 音声ファイルの再生

### 📁 新しいファイル構造

streamlit_viewer/

├── config.py            # 設定ファイル（既存）
├── pages/
│   └── audio_detail.py  # 音声詳細ページ（新規）

### 🔧 変更内容

#### メインページ (db_viewer.py)
- データテーブルに行選択機能を追加 (`on_select="rerun"`)
- 選択時に「音声詳細を表示」ボタンを表示
- データベースクエリに `id`, `scientific_name`, `file_path` を追加

#### 音声詳細ページ (pages/audio_detail.py)
- レコード詳細情報の表示
- 音声ファイルパスの自動解決
- 音声プレイヤー機能
- メインページへの戻りボタン

### 🎵 音声ファイルの自動検索

音声詳細ページでは以下の場所から音声ファイルを自動検索します：

1. データベースに記録された `file_path`
2. `database/audio/completed/` フォルダ
3. `database/audio/failed/` フォルダ  
4. `database/audio/inbox/` フォルダ
5. `database/audio/` フォルダ直下

対応フォーマット: `.wav`, `.mp3`, `.flac`, `.aac`, `.ogg`, `.m4a`
